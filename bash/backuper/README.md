# Backuper  
Un script simple para hacer archivos .bak facilmente, util si es que siempre andas cambiando un archivo y necesitas una copia de seguridad.

## Uso
`./main.sh <archivo>`

## Instalación
`cp main.sh backuper` -> Copiar el archivo a un nombre sin .sh  
`chmod +x backuper` -> Dar permisos de ejecución  
`mv backuper ~/.local/bin` -> Moverlo al bin local  
Listo! Ya lo tienes instalado listo para uso
