# ytdlp menu
Un menu CLI hecho en Bash donde solo tienes que poner el link y unas opciones y ya tienes tu video  
Para utilizarlo tienes que ejecutar `bash main.sh` (o `bash main-extendido.sh`)  

## Instalación
**IMPORTANTE:** en este tutorial se usara como ejemplo main.sh, si tienes main-extendido.sh recuerda de reemplazarlo  
`cp main.sh ytdlp-menu` -> Copiar el archivo a un nombre sin .sh  
`chmod +x ytdlp-menu` -> Dar permisos de ejecución  
`mv ytdlp-menu ~/.local/bin` -> Moverlo al bin local  
Listo! Ya lo tienes instalado listo para uso
