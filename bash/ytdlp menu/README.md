# ytdlp menu
Un menu CLI hecho en Bash donde solo tienes que poner el link y unas opciones y ya tienes tu video  
Para utilizarlo tienes que ejecutar `bash main.sh` (o `bash main-extendido.sh`)  
  
**Si tienes un error porfavor [haz un issue](https://github.com/kittyteggie/basura/issues/new) porque no se si esto este roto ya que le hice muy poco beta-testing, gracias!**
